Сюда кладётся обучающий текст — `input.txt` (любой UTF-8 текст, от ~1 МБ).

- `python prepare_data.py` — скачает «Tiny Shakespeare» (~1 МБ, английский).
- `python prepare_data.py --url <ссылка на .txt>` — скачает любой другой текст.
- Или просто положите свой файл: `cp ~/мой_корпус.txt data/input.txt`.

Для русского подойдут классики из общественного достояния (Пушкин, Толстой,
Чехов) — например, тексты с Project Gutenberg или Викитеки, склеенные в один файл.
Сами тексты в git не коммитятся (см. `.gitignore`).
