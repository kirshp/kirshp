### Hi, I'm Kirill 👋

I build **data products** — I take messy public sources (federations, statistical
agencies, OpenStreetMap, official PDFs) and turn them into fast, multilingual,
self-updating web apps. Solo, static-first, no heavy frameworks.

Based in Madeira 🇵🇹 · open to conferences & collaborations (WebSummit Lisbon 2026).

---

#### 🌿 [Madeira Ative](https://github.com/kirshp/madeira-ative) — [live ↗](https://shpara.com/madeira)
Every race, trail and levada on Madeira in one place, in **six languages**.
Full event calendar, the official Trail Madeira race quadro, a guide to all
classified levadas with **live open/closed status**, 2D + real **3D terrain maps**,
and island news auto-translated on ingest.
`Static HTML · vanilla JS · MapLibre GL (3D) · Leaflet · Python parsers · daily GitHub Actions`

#### 📊 [BullDozer](https://github.com/kirshp/bulldozer) — [live ↗](https://shpara.com/bulldozer)
Marketing analytics & research — **136 public datasets** (IMF, World Bank,
Gapminder, WVS, V-Dem…), interactive charts and **231 country profiles**.
`Astro · hand-written JS · open data`

**Principles I build by**
- Only public, **sourced** data — every figure carries its origin
- No client framework — fast on any phone, installable, offline-tolerant
- **Fresh by itself** — parsers + GitHub Actions keep it current with zero manual work
