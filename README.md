### Azenha AI

**Data products, built end to end.** Messy public sources — federations,
statistical agencies, OpenStreetMap, official PDFs — turned into fast,
multilingual, self-updating apps. Sourcing, pipelines, interface, store
release. Static-first, no heavy frameworks.

Based in Madeira 🇵🇹 · open to conferences & collaborations (WebSummit Lisbon 2026).

---

#### 🌿 [Madeira Ativa ↗](https://shpara.com/ativa)
Every race, trail and levada on Madeira in one place, in **six languages**.
Full event calendar, the official Trail Madeira race quadro, a guide to all
classified levadas with **live open/closed status**, 2D + real **3D terrain maps**,
and island news auto-translated on ingest. Also a native iOS and Android app.
`Static HTML · vanilla JS · MapLibre GL (3D) · Leaflet · Flutter · Python parsers · daily GitHub Actions`

#### 📊 [BullDozer ↗](https://shpara.com/bulldozer)
The world in numbers — **180 public indicators** (IMF, World Bank, Gapminder,
WVS, V-Dem…), interactive charts, **232 country profiles** and a data quiz.
Native mobile app alongside the site.
`Astro · hand-written JS · Flutter · open data`

#### 📈 [AlfaCat ↗](https://shpara.com/alfacat)
A calm end-of-day markets workbench: screener, watchlist and portfolio kept on
device, a learning glossary, and tools that explain the numbers rather than
shout them. Not a trading terminal — a viewer and a study aid.
`Astro · Flutter · EOD public data`

---

**Principles**
- Only public, **sourced** data — every figure carries its origin
- No client framework — fast on any phone, installable, offline-tolerant
- **Fresh by itself** — parsers + scheduled jobs keep it current with zero manual work
- No accounts, no ads, no tracking — the apps collect nothing
